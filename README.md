# Hi, I'm Rihab Id m'hand ![](https://user-images.githubusercontent.com/18350557/176309783-0785949b-9127-417c-8b55-ab5a4333674e.gif)

**Data & AI Engineer** · Python, SQL, data pipelines and LLM applications · Paris, France

I'm a data science engineer with a Master's in AI from École Centrale de Lyon. I build data pipelines, automations and LLM applications, and I like turning a manual business process into something reliable and well documented.

## What I've worked on

- **Chanel:** automated IT and Learning & Development processes on the Microsoft Power Platform, from ServiceNow and Workday data to AI-assisted incident classification that cut Copilot credit use by about 40%. I also shipped two generative AI agents in Copilot Studio.
- **4D Logiciels:** built the Flask backend and data ingestion of an LLM assistant that turns natural-language questions into database queries, with hybrid retrieval in Weaviate (about 30% better retrieval quality than vector search alone), Docker and GitLab CI/CD.
- **Dell Technologies:** worked on data quality for a customer dataset of over 1 billion records, with entity resolution, quality KPIs and data governance.

## Currently building

A self-improving text-to-SQL agent on Microsoft Foundry that learns from its own SQL execution errors. Repository coming soon.
